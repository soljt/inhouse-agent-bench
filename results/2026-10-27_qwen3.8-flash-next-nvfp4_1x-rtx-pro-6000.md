# Qwen3.8-Flash-Next NVFP4 on 1x RTX PRO 6000: vLLM startup report

2026-10-27 · RunPod Secure Cloud (EU) · first successful serve, then a full suite (28 runs, one agent at a time)

Numbers below are what vLLM reported in its log, not benchmarks.

## Setup

| Item | Value |
| --- | --- |
| GPU | 1x NVIDIA RTX PRO 6000 Blackwell Server Edition, 97,887 MiB |
| Pod RAM limit | 250 GB (`/sys/fs/cgroup/memory.max`). A pod limited to 125 GB was killed while loading weights |
| Template | RunPod PyTorch, plus `cuda-toolkit-13-0` (`CUDA_HOME=/usr/local/cuda-13.0`) |
| vLLM | 0.30.0 |
| Weights | `Inferact/Qwen3.8-Flash-Next-NVFP4`, 183 GB (routed experts NVFP4, the rest BF16, n-gram table BF16 in host RAM), from the container disk |

```bash
vllm serve /root/models/qwen3.8-flash-next-nvfp4 \
  --served-model-name qwen3.8-flash-next \
  --host 127.0.0.1 --port 8000 \
  --tensor-parallel-size 1 \
  --max-model-len 131072 \
  --max-num-seqs 16 \
  --gpu-memory-utilization 0.95 \
  --attention-config.indexer_kv_dtype fp8 \
  --limit-mm-per-prompt '{"image":0,"video":0}' \
  --reasoning-parser qwen3 \
  --enable-auto-tool-choice --tool-call-parser qwen3_coder \
  --api-key "$VLLM_KEY"
```

From the log: `Resolved Engram configuration: EngramConfig(cpu_offload=True, ...)`, so the n-gram table stays in
host RAM without `--engram-config`.

## During the suite

From `bench/vllm_stats.py` over 10:37 to 14:02 (pod clock):

| Running requests | Samples (10 s) | Generation tok/s, mean / max | Prompt tok/s, mean | KV cache %, mean / max |
| --- | --- | --- | --- | --- |
| 1 | 849 | 74.6 / 101.7 | 225 | 8.4 / 18.1 |
| 2 | 7 | 84.4 / 133.3 | 623 | 10.8 / 16.5 |

- No requests ever waited for KV cache or a slot.
- Prefix cache hit rate at the end: 94.9%.
- Warnings: `Triton kernel JIT compilation during inference` for a few kernels (`_fused_post_conv_kernel`,
  `_ple_conv_kernel`, `_qsa_mqa_paged_prefill_kernel`): one-off latency spikes the first time each shape occurs,
  harmless.
- The checkpoint's `generation_config.json` sets the default sampling (`temperature 1.0, top_k 20, top_p 0.95`).
  The harnesses can override it per request.
